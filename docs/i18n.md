# 多语言（Hugo multilingual）约定

王总 2026-10-11 决定（经 Grok Bot 转达，quote_ref grok-bot:t141u）：站点双语，默认中文（zh），另设英文（en），页头有语言切换。

## 语言与 URL
- zh 为默认语言，位于站点根 `/`（`defaultContentLanguageInSubdir = false`），现有 URL（如 `/posts/daily/<日期>/`、`/about/`）保持不变，无需 alias。
- en 位于 `/en/`（如 `/en/about/`）。

## 文件命名（按文件名后缀区分语言）
- `<name>.md` = 中文（默认语言）。每篇稿件必须有此文件。
- `<name>.en.md` = 同一页面的英文版；与中文版同目录同 `<name>`，Hugo 自动把两者关联为译本，不使用 `translationKey`。
- `_index.md` / `_index.en.md` 同理。
- 没有英文版的页面，语言切换链接到英文首页。

## 中文稿中的英文直引
英文原文直引保持原文不变，紧接一行中文译文，以“译文：”开头：

```
> <英文原文，逐字>
>
> 译文：<中文译文>
```

译文属于转述（paraphrase），含译文的稿件不属于低风险，须取得 Codex 结论 APPROVED。是否还需王总批准按稿件类型而定：宏观（macro）、统一系统观（tongyi）、信号卡（signal card）须王总批准；日报（daily）不需要王总批准。译文只忠实翻译：不加判断，不弱化、不强化，原文的保留语气（hedge）照译，不添加原文没有的推测词。

每个 `*.en.md` 都是译本，分类为 R-TRANSLATION，draft_id = `<section>-<name>-en`；**每个** `*.en.md` 都须取得 Codex 结论 APPROVED，不论其中是否含“译文：”行。按 t161u，每篇日报（中文版和英文版）都须取得 Codex APPROVED，日报不再适用低风险自动批准（AUTO_APPROVED）。是否还需王总批准按稿件类型而定：宏观（macro）、统一系统观（tongyi）、信号卡（signal card）须王总批准；日报（daily）不需要王总批准。

## 菜单与界面文字
- 菜单按语言写在 `hugo.toml` 的 `[[languages.<lang>.menus.main]]`。
- 界面文字在 `i18n/zh.toml`、`i18n/en.toml`。

## 与发布门禁的关系
- 现行做法：完整门禁要等发布门禁在新仓库重新落地后才有；在那之前，日报发布的依据是审查与治理 bot 人工核对新 markjin-data main 上的 Codex 记录（核对日期、06:55 截止和中英配对），宏观稿和信号卡另外还要王总批准。中文版和英文版日报各自取得 Codex APPROVED 记录，核对通过后一起合并发布。
- 中文稿路径（`content/posts/<section>/<name>.md`）对应 `draft_id = <section>-<name>`，英文稿 `<name>.en.md` 对应 `draft_id = <section>-<name>-en`。
- 旧仓库（已归档）中的自动门禁不接受带 `.` 的英文文件名；新仓库的门禁重新落地时须支持 `*.en.md`，在此之前英文稿按上面的人工核对处理，不因文件名而停发。

## 英文版稿件
- 中文版（默认）= 英文原文直引 + “译文：”；英文版 = 原英文稿原样放在 `<name>.en.md`（/en/），不改写。
- 每个 `*.en.md` 分类为 R-TRANSLATION，draft_id = `<section>-<name>-en`，都须取得 Codex APPROVED（不限于含“译文：”的稿件）；中文版 draft_id 仍为 `<section>-<name>`。
- 按 t145u：中文版和英文版放在同一个 PR 中；Codex 审查记录两条，每个 sha256 一条，两条的 `reviewed_at` 相同，各自的 `pair_sha256` 指向对方的 sha256；两者一起发布。
- 按 t161u：每篇日报都须取得 Codex APPROVED，没有低风险自动批准。
- 王总批准按稿件类型：macro、tongyi、signal card 须王总批准；daily 不需要。

## 免责声明
- 文章页正文末尾放固定文章免责声明：日报（daily）、宏观（macro）、信号卡（cards）。（统一系统观系列已下架，见上。）部署后的冒烟检查（检查项 `disclaimer`）目前只核对日报正文最后一段；宏观稿、信号卡有页面后再接入，见 docs/smoke-check.md。
- 非文章页正文不放固定文章免责声明：关于页（about）、各栏目的 `_index` 索引页、首页。（此条由协调 bot（Grok Bot）在响应王总 t179u 英文界面问题时制定；王总原话仅为“英文界面下还是有问题，你在排查修改吗”。取代此前“所有内容页都放、没有例外”的规定。）
- 站点页脚的投资提示（`i18n/*.toml` 的 `footer_disclaimer`：“宏观内容仅为分析，不构成投资建议。” / “Macro content is analysis only and is not investment advice.”）不属于上面两条规则，保持不变，所有页面（含非文章页）照常显示。页脚句不能代替文章固定句，计数时不算。
- 生效日期：日报固定句的门禁自 2026-10-12 的日报起生效。此前发表的 2026-10-10、2026-10-11 两份日报已按王总 2026-10-11 23:01 决定（经 Grok Bot 转达，quote_ref t217u）删除（“删除已发表的两份日报，明天开始正式发布”），旧网址返回 404；欢迎文 `2026-10-10-welcome.md` 不是日报，保留，不受该门禁约束。
- 中文页（`<name>.md`）用原句：`本文不含投资建议。`
- 英文页（`<name>.en.md`）用原句：`This article does not constitute investment advice.`
- 两句都必须逐字一致（Grok Bot 转达的决定）；门禁需同时放行这两句精确原文。

## 语言切换
- 语言切换只按 Hugo 的译本配对（`.Translations`）取目标；没有译本时链接到另一语言首页。
